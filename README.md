# Metallurgy Laboratory Internship

## Overview

This repository presents my summer internship experience at the Automotive Parts and Assemblies Testing and Research Company (ITRAC), focusing on practical applications of metallurgical engineering in an industrial laboratory.

## Topics Covered

- Metallographic sample preparation and microstructural examination
- Evaluation of metallic materials and automotive components
- Mechanical and chemical testing methods
- Metallography of cast irons and other engineering materials
- Industrial quality assessment and failure analysis
- Laboratory testing standards and technical reporting

The complete internship report is available in the PDF file included in this repository. It documents the laboratory activities, technical concepts, testing procedures, and key learning outcomes from the internship.
